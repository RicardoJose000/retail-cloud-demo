# Retail Cloud - concept demo

Interactive concept demo of a multi-tenant cloud retail platform: catalog, multi-location inventory, WMS, purchasing, omnichannel orders, loyalty, promotions, returns, local delivery and a reusable POS Connector Framework.

- `index.html` - overview with background video and 3D network view
- `app.html` - Merchant Portal demo (20 modules, sample data)
- `app.html#/sync` - POS offline / replay / reconciliation scenario

Static site, no build step. Sample data only. Stock video: Mixkit (free license).
